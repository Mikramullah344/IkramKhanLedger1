اکرام خان کارپوریشن لیجر — نیا اینڈرائیڈ پروجیکٹ

اہم:
یہ Android Studio کا سورس پروجیکٹ ہے، APK فائل نہیں۔ APK بنانے کے لیے GitHub Actions workflow شامل ہے۔

موجودہ سہولیات:
- آف لائن SQLite ڈیٹا بیس
- اردو انٹرفیس اور PIN لاک (1173)
- کسٹمر: نام، ولدیت، پتہ، فون
- سامان/بل، ایڈوانس، بعد کی وصولی، بقایا سے ڈسکاؤنٹ/کٹوتی
- ہر کسٹمر اور تمام کسٹمرز کا مجموعی حساب
- تاریخ وار لین دین
- کھاتہ شیئر کرنا
- JSON بیک اپ اور ریسٹور

حساب:
بقایا = سامان کی کل قیمت - ایڈوانس - بعد کی وصولیاں - ڈسکاؤنٹ

APK موبائل سے حاصل کرنے کا طریقہ:
1) اس ZIP کو اپنے GitHub ریپوزٹری میں اپ لوڈ/Extract کرکے فائلیں main برانچ میں رکھیں۔
2) GitHub میں Actions کھولیں۔
3) "Build Android APK" ورک فلو چلائیں (یا main پر push کے بعد خود چلے گا)۔
4) مکمل ہونے پر Artifacts میں IkramKhanLedger-debug-apk ڈاؤن لوڈ کریں۔
5) ZIP کھول کر app-debug.apk انسٹال کریں۔

نوٹ: یہ ابتدائی قابلِ استعمال ورژن ہے۔ کاروباری استعمال سے پہلے چند فرضی کسٹمرز کے ساتھ حساب اور بیک اپ/ریسٹور ضرور ٹیسٹ کریں۔
